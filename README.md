# Obsessions

Free skill files from **Obsessions**, a YouTube series by Eftal İleri about building software with AI without breaking it.

Everyone is a vibe coder now. The hard part isn't getting AI to write code; it's keeping the project from falling apart as it grows. Each episode takes one rule I got obsessed with while building my own app with AI, and each folder here gives you the skill files to apply that rule in your own project.

| Episode | Folder | What it gives you |
|---|---|---|
| 1 · One Place | [`01-ssot`](01-ssot/) | A single source of truth system: every piece of information, calculation and operation lives in exactly one place, and your agent checks before it writes a copy. |

New folders are added as new episodes come out.

## How to use a skill

1. Copy the skill folder (for example `01-ssot/ssot-system`) into your agent's skills folder.
2. Tell your agent to use it. Each folder's README has the exact sentence.

The skills are written for coding agents that read skill or rules files (Claude Code, Codex and others). They are plain Markdown, so you can also read them yourself.
